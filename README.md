## 🎯 Présentation Générale

Ce dépôt regroupe une suite complète de **projets réels et opérationnels** en analyse de données, modélisation statistique et ingénierie décisionnelle, conçus pour démontrer l'excellence technique et métier auprès d'institutions internationales et d'entreprises de premier plan :

1. **P1 : Pilotage de la Performance Portuaire & Logistique Multimodale (Cible AGL - Africa Global Logistics)**
   - Analyse du *Turnaround Time* (temps d'attente rade + quai), cadences portiques (EVP/h) et détection des alertes de surestaries (*Demurrage*).
   - Technologies : Python (Pandas, NumPy), SQL, Plotly.

2. **P2 : Analyse Géospatiale & Télédétection Marine Côtière (Cible Blue Ventures)**
   - Cartographie SIG de l'effort de pêche (*CPUE*), bathymétrie, suivi des Aires Marines Protégées (*AMP*) et impact sur la régénération des écosystèmes.
   - Technologies : GeoPandas, Scatter Mapbox, Géostatistique, Python.

3. **P3 : Pipeline d'Audit Qualité & Data Humanitaire KoboToolbox / ODK (Cible IMPACT Initiatives / REACH)**
   - Ingestion d'enquêtes mobiles multisectorielles (*MSNA*), détection d'erreurs enquêteurs (*Speeding*, incohérences démographiques, *outliers* rCSI) et génération automatique du *Cleaning Log*.
   - Technologies : Python, Data Quality Validation, Standards humanitaires.

4. **P4 : Modélisation Prévisionnelle & Suivi des Indicateurs ODD (Cible Expertise France & Nations Unies)**
   - Décomposition de tendances et saisonnalité sur séries temporelles, projection à 12-24 mois avec cônes de confiance 95% et suivi des Objectifs de Développement Durable.
   - Technologies : Time Series Forecasting, Scikit-Learn, Streamlit.

## 🚀 Installation & Lancement Local

```bash
# 1. Cloner le dépôt
git clone https://github.com/ChristopheAnderson/data-analytics-bi-portfolio.git
cd data-analytics-bi-portfolio

# 2. Installer les dépendances
pip install -r requirements.txt

# 3. Lancer l'application interactive Streamlit
streamlit run app.py
```

L'interface sera accessible localement à l'adresse `http://localhost:8501`.
